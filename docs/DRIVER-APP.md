# تطبيق السائق الحقيقي (لاحقاً)
تطبيق الويب/PWABuilder لا يستطيع تتبّع الموقع والتطبيق مغلق. الحل لاحقاً: تغليف `/driver` في تطبيق أندرويد حقيقي
(Capacitor) مع إضافة تتبّع بالخلفية وإشعار ثابت «أنت متاح»، ويُبنى الـ APK تلقائياً على GitHub Actions بنفس مفتاح التوقيع.
Google Play يطلب نموذج تبرير للموقع في الخلفية وفيديو قصير.
حتى ذلك الحين: السائق يُبقي التطبيق مفتوحاً، ويُعتبر «غير متاح» تلقائياً إذا لم يتحدّث موقعه خلال دقيقتين.
