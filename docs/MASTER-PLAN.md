# Aklatak — الخطة الرئيسية: التكاليف، التوسّع، الحماية، والطوارئ

> ارفع هذا الملف مع **آخر نسخة احتياطية (zip)** لأي مساعد تقني، فيعيد المنصّة كما هي أو يوسّعها خلال ساعة.

## 1. المنصّة اليوم
| العنصر | القيمة |
|---|---|
| الموقع | `https://sallatteta-platform.onrender.com` — الإدارة `/admin/` |
| الكود | GitHub خاص `takajiali63-lgtm/sallatteta-platform` (Node 22، بلا إطار) |
| الاستضافة | Render (النشر يدوي) — بصمة النسخة تظهر في «أمان حسابي» |
| قاعدة البيانات | Neon Postgres + **PostGIS** (يُفعَّل تلقائياً) |
| الصور | Cloudflare R2 — bucket `aklatak-photos` |
| الخرائط | Geoapify (مفتاح على الخادم فقط) |
| التطبيق | Android (PWABuilder، الحزمة `com.aklatak.app`، المفتاح في Drive) — يفتح المنصّة نفسها |
| المراقبة | UptimeRobot على `/readyz` |

**متغيّرات Render (الأسماء فقط — القيم في Render/Drive):** `DATABASE_URL`, `SESSION_SECRET`, `ADMIN_WHATSAPP_NUMBER`, `PUBLIC_BASE_URL`, `NODE_ENV=production`, `DATABASE_SSL=true`, `GEOAPIFY_API_KEY`, `ANDROID_PACKAGE_NAME`, `ANDROID_SHA256_CERT_FINGERPRINTS`, `S3_ENDPOINT`, `S3_BUCKET`, `S3_ACCESS_KEY_ID`, `S3_SECRET_ACCESS_KEY`, `S3_PUBLIC_URL`, `S3_REGION=auto` — اختيارية: `REDIS_URL`, `DEEPL_API_KEY`, `ROUTE_BATCH`, `DB_POOL_MAX`, `POSTGIS=off`.

## 2. المبادئ الثابتة (لا تُكسر)
- **كل بلد منفصل**: السلايدرات، البحث، «حواليك»، الأقسام التلقائية — حتى على الحدود. زائر من بلد غير موجود لا يرى أي محل.
- **الحرفي والطبّاخ المنزلي**: موقعهما لا يظهر أبداً. المحلات: «الطريق إليه» + الاتصال + واتساب.
- **المسافة**: بالطريق (أقرب 20 أولاً، الباقي عند الوصول إليه)، وإلا «≈» تقريبية — لا أرقام كاذبة.
- **الإعلانات**: لكل العالم (قرار المالك).
- **الحذف نهائي، والانتهاء إخفاء**: عند التجديد يرجع الحساب بكل صوره ومعلوماته.

## 4. التوسّع المليوني — بالترتيب، بلا إعادة كتابة
1. **Render Starter** (لا ينام) ← **Standard** ← **عدة سيرفرات** (Scaling) — الخادم بلا حالة.
2. **`REDIS_URL`** عند سيرفرين أو أكثر (ذاكرة وحدود مشتركة).
3. **رابط Neon المجمّع (Pooled)**، و`DB_POOL_MAX` بحيث: عدد السيرفرات × الحد < حدّ قاعدة البيانات.
4. **خدمة عمل منفصلة** للمهام (`RUN_JOBS=false` على سيرفرات الويب + `scripts/worker.js`).
5. **سيرفر طرقات خاص (OSRM)** عندما تتجاوز Geoapify ~1,000 بحث جديد يومياً.
6. **نطاق مخصّص للصور** (`images.<الدومين>`) فوق R2 مع كاش Cloudflare.
7. **نسخة قراءة** لقاعدة البيانات + **اختبار تحمّل على نسخة تجريبية** قبل كل قفزة.
مُقاس اليوم: معالج واحد ≈ 250–300 طلب/ثانية، 100 مستخدم متزامن بلا أخطاء.

## 5. التوفير
- مسافة الطريق لأقرب 20 فقط، والباقي عند الوصول؛ حفظ لكل ~100 م؛ «≈» عند انتهاء الرصيد — لا خصم تلقائي.
- الخطط المجانية ما دامت كافية؛ الترقية فقط عند الحاجة (المراقبة + سجلّ Render).
- الاستيراد من OpenStreetMap (مجاني وقانوني) — **لا نسخ من Google Maps** (ممنوع).

## 6. الحماية
- **الحسابات**: GitHub + Render + Gmail + Cloudflare + Neon — تحقّق بخطوتين، كلمات سر لا تُشارك. بصمة الإدارة (Passkey) + رموز احتياطية.
- **في الكود (مُختبر)**: رفض كل ما يخصّ الإدارة بلا دخول، حماية CSRF، حظر تخمين كلمات السر، لا قراءة لملفات الخادم، لا حقن SQL، رؤوس أمان، قطع الطلبات الضخمة، الوكيل محصور ببلده **على الخادم**، التحقق من شهادة قاعدة البيانات.
- **دورياً**: تبديل مفاتيح Neon وGeoapify وR2 التي ظهرت في المحادثات؛ تنزيل نسخة احتياطية شهرياً إلى Drive.

## 7. خطة الطوارئ (Runbook)
| ماذا حدث | ماذا نفعل |
|---|---|
| **Render توقّف/اختفى** | خدمة جديدة (Render آخر أو Railway أو Fly.io): نرفع **zip النسخة الاحتياطية**، نضع المتغيّرات (القسم 1)، نوجّه الدومين — **~ساعة**. |
| **قاعدة البيانات تضرّرت** | Neon «استرجاع لنقطة زمنية» — أو قاعدة جديدة + **استرجاع النسخة الاحتياطية** من الإدارة. |
| **Cloudflare R2 توقّف** | الصور القديمة تتعذّر مؤقتاً، والجديدة تُحفظ في قاعدة البيانات تلقائياً إن أُزيلت متغيّرات `S3_*`؛ لاحقاً «نقل الصور». |
| **Geoapify توقّف/انتهى الرصيد** | قاطع الدائرة → «≈» تقريبية؛ البحث يعمل. |
| **ضغط مفاجئ** | زيادة السيرفرات في Render + `REDIS_URL`، ثم ترقية Neon. |
| **فقدان GitHub** | النسخة الاحتياطية تحتوي الكود كاملاً → مستودع جديد. |
| **فقدان مفتاح التطبيق** | لا بديل — **احفظ مجلد PWABuilder في Drive** (مكانين). |

**للعودة خلال ساعة، احتفظ دائماً بـ:** آخر **zip نسخة احتياطية** (من الإدارة) + **هذا الملف** + **قيم المتغيّرات** (في Drive) + **مجلد مفتاح التطبيق**.
