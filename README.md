# أكلتك (Aklatak) — منصة طلبات وتوصيل بلا عمولة

> النسخة **8.4.0** · Node.js 22 · PostgreSQL · أربع لغات (العربية الفصحى، English، Français، Español)

**أكلتك** تربط الزبائن بالمتاجر القريبة (مطاعم، سوبرماركت، صيدليات، حِرفيون، متاجر أونلاين) وبالسائقين المستقلين.
- لا عمولة على الطلبات.
- المنصة لا تمسك المال.
- الدخل من الاشتراكات فقط، عبر Google Play وApp Store.

## ما في المنصة

| الواجهة | الرابط | لمن |
|---|---|---|
| تطبيق الزبون | `/` | تصفّح المتاجر القريبة، الطلب والمتابعة، «اطلب سائقاً» مع عروض أسعار السائقين، مساعد كل متجر |
| تسجيل متجر | `/join` | المتاجر الجديدة (القسم، الموقع، الساعات، الباقة) |
| لوحة المتجر | `/store` | الطلبات، المنتجات (حتى الآلاف، مخزون، عروض، رفع Excel/CSV)، الفروع، الاشتراك، المال مع السائقين، المدير الذكي |
| تطبيق السائق | `/driver` | استقبال الطلبات القريبة، عروض الأسعار، التوصيل، المال للمحلات، خدماته الخاصة |
| الإدارة | `/admin/` | كل شيء: المشتركون، التوصيل، الأسعار، المال، المدير الذكي، الفوترة، التصاميم، البلدان، ربط Claude |

## التشغيل

```bash
npm install          # الاعتمادية الوحيدة: pg
npm start            # بلا DATABASE_URL يعمل على SQLite محلياً (./data/dev.sqlite)
npm test             # 431 اختباراً
node scripts/stress-v84.js --db postgres://…/test   # اختبار ضغط وتداخل (ليس على الإنتاج)
node scripts/gen-spec.js                           # يعيد توليد API-ROUTES.md و DB-SCHEMA.md
```

الإنتاج على Render وNeon. البناء والمتغيّرات والرفع والرجوع في [`docs/HANDOVER.md`](docs/HANDOVER.md).

## قواعد أساسية (التفاصيل في HANDOVER §6)

- المنصة **لا تستلم ولا تحوّل** أموال الطلبات، والسجلات المالية **لا تُحذف**.
- الاشتراكات **عبر Google Play وApp Store فقط**، والخادم يتحقق بنفسه.
- **عزل كامل:** كل حساب يرى ما يخصّه فقط، وكل بلد منفصل.
- الأسعار تُحسب **على الخادم**. لا أسرار في الواجهات.
- كل نص جديد **بأربع لغات**، والعربية فصحى.
