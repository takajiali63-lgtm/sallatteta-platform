# سلة تيتا — منصة الطبخ المنزلي

> كل نصوص الموقع بالعربية الفصحى وبخطاب موجّه للجميع (`locales/ar.json`).

منصة مستقلة تربط الزبونة بستات البيت. الزبونة تكتب شو بدها، تختار ضيعتها، وبتطلعلها الستات اللي **بيوصلوا على هالضيعة**، الأقرب أولاً. بتختار ست وبتنتقل لـ WhatsApp والطلب مكتوب. بعدها السعر والكمية والتوصيل والدفع بينهن مباشرة.

> التطبيق (Android / iPhone): [`docs/MOBILE.md`](docs/MOBILE.md).
> خطط النمو: [`docs/EXPANSION-PLAN.md`](docs/EXPANSION-PLAN.md) و[`docs/SCALING-PLAN.md`](docs/SCALING-PLAN.md).
> **ابدأ من هنا:** [`docs/HANDOVER.md`](docs/HANDOVER.md) — الروابط، الحسابات، الاستضافة، كيفية التحديث، القرارات، وسجل النسخ.
> المواصفات التقنية الكاملة (قاعدة البيانات وكل الـ API) في [`docs/SPEC.md`](docs/SPEC.md) — مرجع لأي تطبيق موبايل.

## شو في بالمنصة

| الصفحة | الرابط | لمين |
|---|---|---|
| الرئيسية | `/` | الزبائن: كتابة الطلب، سلايدر صور الأكل، سلايدر الطبّاخات، البحث بالاسم، «طبّاخاتي»، تقييم آخر طبخة |
| صفحة الست | `/c/<رقم>` | صورها، وصفها، الضيع اللي بتوصلها، النجوم، الإعجاب، مشاركة، «اطلبي منها»، «شكوى أو ملاحظة» |
| اشتراك ست | `/join` | الست بتختار ضيعتها، وبتطلعلها الضيع القريبة (مش مختارة) لتختار وين بتوصل |
| حساب الست | `/account` | دخول برقم WhatsApp + كلمة سر: أرقامها، صور أكلاتها (حتى 12)، تعديل صفحتها وضيعها، تغيير كلمة السر |
| الإدارة | `/admin/` | الستات، الاشتراكات، كلمات السر، الشكاوي، الإنذارات، الصور، زيادة ضيع. **ما في رابط إلها من الموقع العام** |

## القواعد الأساسية

- **الزبون لازم يحدد موقعه بالـ GPS** (إجباري، بالصفحة الرئيسية وبزر «اطلب الآن» بصفحة الطبّاخ).
- **الطبّاخ بيظهر للزبون** فقط إذا: مقبول + اشتراكه فعّال وما خلص + بيوصل على بلدة الزبون (البلدة الأقرب لموقعه، أو أي بلدة ضمن 1.5 كم منه). **الترتيب من الأقرب للأبعد.**
- **الاشتراك:** تحديد الموقع بالـ GPS **إجباري**. بعدو بتطلع البلدات والمناطق حوالين موقع الطبّاخ من الخريطة (OpenStreetMap)، كلها مش مختارة، وهو بيختار وين بيوصل. خانة البلدة أو المنطقة اختيارية، للمعلومات بس.
- **الترتيب:** حسب المسافة بين الزبونة (موقعها أو وسط ضيعتها) وبيت الست.
- **رقم الست ما بيبين أبداً** بالموقع. رابط WhatsApp بينعمل على السيرفر بس لما الزبونة تضغط.
- **التقييم بالنجوم:** بس للزبونة اللي تواصلت فعلاً مع الست عبر المنصة (رمز سري بيتخزن على تلفونها). بيبين للعموم كمعدّل.
- **الشكاوي والملاحظات:** بتوصل **للإدارة بس**. ما بتبين على صفحة الست ولا بحسابها. الإدارة بتقرر: إنذار للست (بينسجل + بيفتح WhatsApp برسالة جاهزة) أو «تمّت المعالجة».
- **الإعجاب:** ❤ مرة وحدة لكل جهاز.
- **الاشتراك المنتهي:** بيوقف ظهور الست تلقائياً (فحص كل 15 دقيقة + عند كل بحث).

## البلدات

- في 180 بلدة أساسية بـ `src/db/seed-data.js`، موزّعة عالـ 26 قضاء.
- **من الخريطة:** لما طبّاخ أو زبون يحدد موقعه، السيرفر بيجيب من OpenStreetMap كل البلدات والمناطق ضمن 15 كم، وبيحفظها. هيك اللائحة بتكبر لحالها، وفيها الضيع الزغيرة. كل منطقة بحجم 5 كم تقريباً بتنطلب مرة وحدة بالشهر، والباقي من الحفظ.
- إذا الخريطة ما ردّت، بيطلعلو البلدات المحفوظة عنّا، فما بيوقف شي. وبينكتب بالسجل سطر `[osm]`.
- البحث بيفهم الكتابة المختلفة: «قرعون» = «القرعون».
- بتقدر تزيد بلدة بإيدك من الإدارة ← «إضافة بلدة».

## دليل الإدارة

**تفعيل ست قدّمت طلب:** بتوصلك رسالة WhatsApp فيها الاسم، الرقم، الضيعة، الضيع اللي بتوصلها، والمدة. بعد الدفع: الإدارة → «طلبات جديدة» → الست → «تفعيل الاشتراك». تاريخ الانتهاء بينحسب تلقائياً حسب المدة، أو بتكتبيه بإيدك.

**حساب الست:** بصفحة الست بالإدارة → «كلمة سر جديدة + إرسالها عـ WhatsApp». بيطلع كلمة سر سهلة (مثل `kmrt4827`) وبيفتح WhatsApp برسالة فيها رابط الموقع ورقمها وكلمة السر. إذا نسيتها، نفس الزر بيعطيها وحدة جديدة وبيطلّعها من كل الأجهزة.

**الشكاوي:** تبويب «الشكاوي والملاحظات» (الرقم الأحمر = الجديدة). لكل شكوى: «إنذار للست» (رسالة جاهزة بتقدري تعدّليها، وبينسجل عدد الإنذارات) أو «تمّت المعالجة». إذا الزبونة كتبت رقمها، بتقدري تحكيها مباشرة.

**الصور:** بصفحة الست بالإدارة بتشوفي كل صورها، وفيكي تمحي أي صورة مش مناسبة.

**تعديل ست:** الاسم والرقم ما بتقدر تغيّرهم الست، بس الإدارة. الضيع والوصف والصورة والخدمات بتقدر تغيّرهم هي أو الإدارة.

**اسم مستخدم الإدارة** مش حسّاس للأحرف الكبيرة والصغيرة (`Ali.Takaji` = `ali.takaji`).

## التشغيل محلياً

المتطلبات: **Node.js 22.5 أو أحدث**. ما بتحتاجي PostgreSQL محلياً (بيستعمل SQLite).

```bash
cp .env.example .env
npm install
npm run seed:demo      # 4 ستات تجريبيات حول زحلة، كلمة السر لكلن: teta1234
npm run dev            # http://localhost:3000
npm test               # 98 اختبار
```

## Environment variables

| المتغير | إلزامي؟ | الوصف |
|---|---|---|
| `DATABASE_URL` | نعم | `postgres://…` بالإنتاج. محلياً: `sqlite:./data/dev.sqlite` |
| `SESSION_SECRET` | نعم بالإنتاج | سر عشوائي، 32 حرف عالأقل |
| `ADMIN_WHATSAPP_NUMBER` | نعم | رقم WhatsApp الإدارة بصيغة دولية أرقام بس، مثل `96171123456` |
| `ADMIN_PATH` | لا | مسار لوحة الإدارة (الافتراضي `/admin`) |
| `ADMIN_BOOTSTRAP_USERNAME` / `ADMIN_BOOTSTRAP_PASSWORD` | لأول مرة بس | بيعمل حساب إدارة أو بيغيّر كلمة سرّه. امحيهم بعد الدخول |
| `PUBLIC_BASE_URL` | لا | رابط الموقع برسالة كلمة سر الست (مثلاً بعد ربط دومين). الافتراضي: الرابط اللي فاتت منه الإدارة |
| `TRUST_PROXY` | على Render: `1` | لقراءة IP الحقيقي |
| `DATABASE_SSL` | مع Neon: `true` | اتصال مشفّر بالقاعدة |
| `DEFAULT_COUNTRY_CODE` | لا | الافتراضي `961` |
| `NODE_ENV` | على Render: `production` | Secure cookies وHSTS |

## قاعدة البيانات

ما في شي يدوي. عند كل تشغيل، السيرفر بينشئ الجداول والأعمدة الناقصة، وبيزيد الضيع إذا تغيّر `SEED_VERSION`. الستات القدام (نظام الكيلومترات) بيتحوّلوا تلقائياً لضيع: كل الضيع اللي ضمن نطاقها القديم.

## النشر الحالي (Render + Neon)

- الخدمة: `sallatteta-platform` على Render (خطة مجانية، بتنام بعد 15 دقيقة وأول زيارة بتاخد حوالي دقيقة).
- القاعدة: Neon Postgres (مجانية، ما بتخلص).
- الـ repo على GitHub فيه ملف `sallatteta-platform.zip` + README بس. أمر البناء بيفك الملف. **للتحديث:** ارفعي zip جديد بنفس الاسم مكان القديم، وRender بينشر لحالو.
- **دومين خاص:** Render → الخدمة → Settings → Custom Domains، وبعدين حطي `PUBLIC_BASE_URL`.
- **تغيير الاسم أو الشعار:** كل النصوص بـ `locales/ar.json` (`brand.name`)، والشعار بـ `public/assets/favicon.svg`.

## الأمان والخصوصية

- كلمات السر مشفّرة بـ scrypt. جلسات بكوكي `HttpOnly` + `SameSite=Strict` + فحص CSRF.
- حد لعدد المحاولات على البحث، الطلبات، الدخول، الشكاوي.
- موقع الزبونة بيتقرّب لحوالي 100 متر بالمتصفح، وبيتخزن مقرّب لحوالي 1 كم. ما في عناوين.
- IP بيتخزن كـ hash بس. الإعجاب والزيارات بـ رمز جهاز مشفّر.
- الصور بتتصغّر بالتلفون قبل الرفع (حوالي 100–200 KB للصورة).

## ملاحظة للتحديثات

عند كل تحديث للواجهة، غيّري رقم `?v=` بروابط الـ JS/CSS (بالـ HTML وبأسطر `import`) لتنزل النسخة الجديدة عند الجميع فوراً:

```bash
grep -rl "?v=420" public admin-ui | xargs sed -i "s/?v=420/?v=421/g"
```
